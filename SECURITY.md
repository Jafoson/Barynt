# Security policy

## Reporting a vulnerability

Please **do not open a public issue** for a security problem.

Report it privately through GitHub:
[Report a vulnerability](https://github.com/barynt-dev/barynt-web/security/advisories/new).

Include what you found, how to reproduce it, which version it affects (shown in
the sidebar under your name) and, if you can, what an attacker could do with it.
We will answer as soon as we can, work with you on a fix and credit you in the
release notes if you like.

## Which versions get fixes

The **latest release**. Please update before you report, and say so if the
problem is still there.

## What is in scope

Barynt itself: the app, the REST API, the MCP server, the installer, the Docker
image and the Helm chart. Problems in a dependency are best reported to that
project; if Barynt uses it in a way that makes it exploitable, tell us.
